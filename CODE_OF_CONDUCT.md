# Code of Conduct

## Commitment

Samsarix Agent Ethics aims to provide a respectful, inclusive, and constructive environment for
everyone who participates. Contributors, maintainers, and users are expected to help keep project
spaces safe and useful regardless of identity, background, experience, or ability.

## Expected behavior

- Communicate respectfully and focus criticism on ideas and code.
- Welcome questions and differing technical perspectives.
- Give actionable feedback and accept correction in good faith.
- Respect privacy, boundaries, attribution, and consent.
- Take responsibility for mistakes and repair harm where possible.

## Unacceptable behavior

- Harassment, threats, stalking, discrimination, or sexualized attention.
- Slurs, demeaning language, deliberate intimidation, or sustained disruption.
- Publishing another person's private information without permission.
- Abusing project access, moderation authority, or reporting channels.
- Retaliating against someone for raising a good-faith concern.

## Scope

This code applies in this repository's issues, pull requests, discussions, reviews, and other
project-controlled spaces. It also applies when someone officially represents the project.

## Reporting conduct concerns

Do not publish personal or sensitive incident details in a public issue. Email
[contact@samsarix.com](mailto:contact@samsarix.com) or contact a maintainer through another private
channel available to you.

Security vulnerabilities follow the separate process in [SECURITY.md](SECURITY.md).

The repository does not promise a response-time SLA or formal appeal committee. Samsarix LLC should
add those only when they are staffed and can be honored.

## Enforcement

Project maintainers may remove content, restrict participation, or take other proportionate action
to protect project spaces. Decisions should consider context, impact, prior behavior, and the
safety of affected people. Reports should be handled as privately as the available project tools
allow, without promising confidentiality that cannot be guaranteed.

## Attribution

This project-specific policy is informed by common open-source community standards, including the
[Contributor Covenant](https://www.contributor-covenant.org/), the
[Django Code of Conduct](https://www.djangoproject.com/conduct/), and the
[Python Community Code of Conduct](https://policies.python.org/python.org/code-of-conduct/).
