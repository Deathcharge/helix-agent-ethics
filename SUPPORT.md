# Support

## Product support

For installation, integration, or usage help, email
[support@samsarix.com](mailto:support@samsarix.com). Include the package version, Python version,
operating system, the command or API being used, and a minimal sanitized reproduction.

Public, non-sensitive defects can be filed through
[GitHub Issues](https://github.com/Deathcharge/samsarix-agent-ethics/issues). Do not attach
credentials, private policies, production action inputs, personal data, or audit logs.

## Security and conduct

- Security vulnerabilities: follow [SECURITY.md](SECURITY.md).
- Conduct concerns: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Company contact

Company, partnership, licensing, and brand-use questions can be sent to
[contact@samsarix.com](mailto:contact@samsarix.com).

No response-time SLA or paid support entitlement is implied by this community support channel.
